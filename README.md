# trialWorks

A small React + Vite demo for switching between light, dark, and system themes.

## Run the demo locally

After cloning or downloading this repository, open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173) to use the demo. The theme selection is saved in your browser on that device.

## Production build

```bash
npm run build
npm run preview
```
